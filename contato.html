EXPLICAÇÃO DO DESENVOLVIMENTO DO SITE

PARA O PROFESSOR RÔMULO

Olá, Professor Rômulo! Esta página foi criada para explicar como desenvolvi o site sobre Hollow Knight com a ajuda do ChatGPT.

Meu nome é Emilly, e este projeto foi uma jornada de aprendizado incrível! Abaixo, explico detalhadamente como cada parte do site foi construída.

1. CONCEITO E ESTRUTURA BÁSICA

O site foi planejado para ser uma homenagem ao jogo Hollow Knight, com foco na experiência imersiva do usuário.

Estrutura básica:

  • Página inicial com introdução ao jogo
  • Página de personagens com cards interativos
  • Mapa interativo de Hallownest
  • Galeria de imagens oficiais
  • Página de contato (esta que você está vendo)

Todas as páginas seguem um design coerente com a estética do jogo.

2. DESIGN E ESTÉTICA

O design foi inspirado diretamente no visual de Hollow Knight:

  • Cores: Paleta de azuis e tons escuros, remetendo às cavernas de Hallownest
  • Tipografia: Fonte "Press Start 2P" para manter o estilo pixel art
  • Elementos visuais: Bordas, sombras e efeitos que lembram o jogo
  • Responsividade: Layout adaptável para diferentes tamanhos de tela

Usei CSS avançado para criar efeitos como hover, transições e animações.

3. PÁGINA DE PERSONAGENS

A página de personagens foi uma das mais trabalhadas:

  • Cards interativos: Cada personagem tem seu próprio card com imagem e descrição
  • Efeitos visuais: Hover effects, sombras e transições suaves
  • Conteúdo: Informações sobre cada personagem, incluindo falas características
  • Design responsivo: Layout que se adapta a diferentes dispositivos

Usei Flexbox para organizar os cards de forma dinâmica.

4. MAPA INTERATIVO

O mapa interativo foi o elemento mais complexo do site:

  • Expansão ao clicar: O mapa se expande com animação suave
  • Detalhes das áreas: Cada região pode ser clicada para ver informações
  • Efeito de digitação: As informações aparecem letra por letra
  • Navegação intuitiva: Fácil de usar e entender

Implementei isso com JavaScript puro, sem bibliotecas externas.

5. GALERIA DE IMAGENS

A galeria apresenta imagens oficiais do jogo:

  • Layout em grid: Organização visualmente agradável das imagens
  • Modal de detalhes: Ao clicar em uma imagem, abre-se um modal com informações
  • Efeito de tremor: As imagens tremem levemente ao serem clicadas
  • Informações detalhadas: Cada área tem sua descrição, desafios e objetivos

Usei CSS Grid para criar o layout responsivo da galeria.

6. DESAFIOS E APRENDIZADOS

Durante o desenvolvimento, enfrentei alguns desafios:

  • Curva de aprendizado: Aprender JavaScript para a interatividade
  • Design responsivo: Garantir que o site funcionasse bem em todos os dispositivos
  • Otimização de performance: Manter o site rápido mesmo com animações
  • Compatibilidade: Testar em diferentes navegadores

Superei esses desafios com pesquisa, testes e a ajuda do ChatGPT.
